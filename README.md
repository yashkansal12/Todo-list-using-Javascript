# ✅ Todo List App

A simple and interactive Todo List application built using **HTML, CSS, and JavaScript** to help manage daily tasks efficiently.

## 🚀 Features

- Add new tasks
- Delete specific task
- Confirm before delete all task
- Delete all task in on click

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling
- **JavaScript** – Logic and DOM manipulation
